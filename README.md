# AI Text Analyzer

A Python project that analyzes text files and generates AI-powered summaries using the OpenAI API.

## Features

- Word count
- Sentence count
- Character count
- Most repeated word detection
- AI-generated summaries

## Technologies Used

- Python
- OpenAI API

## How to Run

1. Install Python
2. Install OpenAI package

```bash
pip install openai
```

3. Add your OpenAI API key
4. Run:

```bash
python textanalizer.py
```

## Example

The program reads a text file, analyzes its contents, and generates an AI summary automatically.
